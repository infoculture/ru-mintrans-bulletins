# Устройство сайта mintrans.gov.ru

Сайт работает на October CMS (PHP). Весь контент отдаётся в серверном HTML, JavaScript для
разбора не нужен. API и RSS для документов нет.

## URL-шаблоны

| Сущность | URL |
|---|---|
| Разделы «Результатов деятельности» | `/ministry/results` → `/ministry/results/{id}` |
| Список документов раздела | `/ministry/results/{id}/documents?page=N` (9 документов на странице) |
| Новости раздела | `/ministry/results/{id}/events` |
| Карточка документа | `/documents/{type}/{id}` |
| Файл | `/file/{id}` |
| Поиск по документам | `/documents?type={type}&q={текст}&page=N` (4 документа на странице; `type=0` — все типы) |
| Справочник по регионам | `/transport_of_russian/`, `/transport_of_russian/{округ}/{регион}` |

ID документа глобальный: тип в `/documents/{type}/{id}` сайт игнорирует. Ссылки на один и
тот же документ встречаются с разными `type` и с параметром `?type=`.

Разделы «Результатов деятельности»:

награждении; 14 — противодействие коррупции; 15 — протоколы; 16 — стенограммы; 17 — перечни

## Список документов раздела

```html
<div class="document-list">
  <div class="document-list-item">
    <span class="date-span">11 Декабря 2025</span>
    <a href="/documents/7/15038"><p class="document-text fc-blue">Название</p></a>
    <div class="document-download">
      <a class="download-item pdf" download href="/file/552522">… <span>(2493 kB)</span></a>
    </div>
  </div>
</div>
<div class="pagination">
  <ul class="pagination-wrap">
    <li class="pagination-item active"><a href="">1</a></li>
    <li class="pagination-item"><a href="…/documents?page=2">2</a></li>
    <li class="pagination-item"><a>...</a></li>
    <li class="pagination-item"><a href="…/documents?page=9">9</a></li>
    <li class="pagination-item next"><a href="…/documents?page=2"></a></li>
  </ul>
</div>
```

У активной страницы `href` пустой: её номер есть только в тексте.

## Карточка документа

```html
<div class="content">
  <h1>Результаты и основные направления деятельности на 2009–2011 гг.</h1>
  <span class="date-span dark">Опубликовано 1 Января 2010</span>
  <div class="text-block">…</div>
  <p class="fc-gray fz-xmedium">Файлы для скачивания</p>
  <ul class="download-list">
    <li class="download-list-item pdf">
      <a href="/file/395019" download>Название <span class="fc-gray"> (794 kb)</span></a>
    </li>
  </ul>
</div>
```

- Тип вложения задан CSS-классом `li`: `pdf`, `doc`, `docx`, `xls`, `rar`, `zip`.
- Размер записан в `<span>` в скобках.
- В названиях вложений бывают свои скобки: «(Приложение 1)».
- Встречается ссылка без названия, только с размером (`/documents/7/9103`). Тогда
  названием файла служит название документа.

## Бюллетень «Транспорт России» на сайте (03.11.2026)

- В разделе «Статистика» 73 документа за 2010–2025 годы. Из них 52 — выпуски
  информационно-статистического бюллетеня «Транспорт России». Остальное — формы закупок,
  доклады о деятельности, индикаторы программ, численность работников, бюджет; парсер их не
  собирает.
- Ещё один выпуск есть только в поиске: «Январь–сентябрь 2017 года» (`/documents/7/9103`).
- Итого 53 выпуска с периодами от 2011 года до января–сентября 2025 года, нарастающим итогом:
  I квартал, полугодие, 9 месяцев, год.
- У выпуска один файл, у «Январь–сентябрь 2022» — два (pdf и doc). Всего 54 файла:
  29 doc, 17 pdf, 5 docx, 3 rar с doc внутри. HTML-таблиц на карточках нет, все данные в
  файлах.
- Вёрстка менялась: doc в 2011–2016 годах, затем docx и doc, с 2022 года — pdf.
- Последний выпуск опубликован 11.12.2025 («9 месяцев 2025 года»).

## Поиск по документам

Поиск ищет подстроку в названии, без морфологии; на странице 4 документа. `crawl` ищет по
двум подстрокам: «бюллетень» (14 страниц выдачи) и «Транспорт России» (15 страниц). В выдаче
кроме выпусков есть приказы, информационные бюллетени о воздушном пространстве, материалы
форума «Транспорт России». Выпуск отбирается по словам «информационно-статистический
бюллетень» в названии.
